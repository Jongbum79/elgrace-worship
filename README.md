# 주은혜교회 주일 예배 뷰어 (Elgrace Worship)

대한예수교장로회 주은혜교회(Elgrace Presbyterian Church) 주일 예배 순서, 찬송가 악보 뷰어 및 성경 본문 리더 웹 어플리케이션입니다.

- **공식 사이트**: [https://jongbum79.github.io/elgrace-worship/](https://jongbum79.github.io/elgrace-worship/)
- **디자인 철학**: Apple 휴먼 인터페이스 가이드라인 기반의 미니멀리즘, 글래스모피즘(Glassmorphism) 및 반응형 모바일 최적화

## 🌟 주요 기능
1. **주일 예배 안내 순서**: 최신 주보(2026년 9월 27일) 기반 순서 실시간 연동
2. **찬송가 악보 뷰어**: 
   - 93장, 304장, 50장, 445장 및 256장 고화질 악보 내장
   - 찬송가 빠른 검색 모달을 통한 번호별 악보 접근
3. **성경 본문 뷰어**: 
   - 오늘 본문(창세기 39장 1~23절) 개역개정 전문 수록
   - 글자 크기(A-, A+) 조절 기능
4. **신앙고백 및 소식**: 사도신경 전문 및 금주 주요 교회 일정 모달
5. **다크 모드 지원**: 시스템 설정 연동 및 수동 라이트/다크 모드 토글
